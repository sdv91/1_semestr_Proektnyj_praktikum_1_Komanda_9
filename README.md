# Кейс 4

## Название

Бинарное прогнозирование срыва сроков доставки еды (SLA)

## Главная задача кейса

Требуется классифицировать риск задержки доставки заказа более чем на 5 минут от обещанного времени на этапе оформления, используя параметры ресторана, рейтинг курьера, погодные условия и пробки.
